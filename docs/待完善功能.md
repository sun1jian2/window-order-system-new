### 2. 后端功能完善建议

为了将系统从“可用”提升到“好用”和“健壮”的企业级标准，建议按以下优先级补充功能：

#### (1) 引入 Redis 缓存 (优先级：高)
**原因**：目前系统完全依赖数据库，字典数据、配置信息、用户权限等高频读取的数据会造成数据库压力。
**功能点**：
*   **业务缓存**：缓存数据字典、商品分类、用户角色权限。
*   **分布式锁**：防止重复提交（如订单重复创建）。
*   **Session共享**：为未来多实例部署做准备。

**实现方案**：
在 `window-order-common` 或各服务 `pom.xml` 中引入依赖：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-redis</artifactId>
</dependency>
<!-- 推荐引入 Redisson 处理分布式锁 -->
<dependency>
    <groupId>org.redisson</groupId>
    <artifactId>redisson-spring-boot-starter</artifactId>
    <version>3.27.0</version>
</dependency>
```

#### (2) 完善监控体系 (优先级：高)
**原因**：微服务架构下，服务实例多，无法人工排查哪个服务宕机或内存溢出。
**功能点**：
*   **健康检查**：暴露 `/actuator/health` 接口，供 K8s 或 Nacos 检测服务存活。
*   **指标监控**：监控 JVM 内存、线程池、数据库连接池状态。

**实现方案**：
引入 Actuator 依赖：
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```
在 `application.yml` 中暴露端点：
```yaml
management:
  endpoints:
    web:
      exposure:
        include: "health,info,metrics"
```

#### (3) 集成定时任务 (优先级：中)
**原因**：系统缺乏自动化的后台处理能力。
**功能点**：
*   **数据清理**：每天凌晨清理 7 天前的 Excel 导出临时文件。
*   **状态同步**：自动取消超过 24 小时未支付的订单。
*   **报表统计**：每日生成销售日报、月报数据，存入统计表，提高 Dashboard 查询速度。

**实现方案**：
简单场景使用 `@Scheduled` (需配合 Redis 锁防止多服务重复执行)，复杂场景推荐集成 **XXL-JOB**。

#### (4) 优化全局日志审计 (优先级：中)
**原因**：现有的 `LogAspect` 使用 `@AfterReturning`，只能记录成功的操作。一旦业务报错，日志里没有任何记录，不利于排查问题。
**改进建议**：
*   改为 `@Around` 环绕通知。
*   增加 **执行耗时** 记录，便于发现慢接口。
*   增加 **异常捕获**，记录异常类型和堆栈信息，并标记日志状态为“失败”。

**代码参考思路**：
```java
@Around("@annotation(log)")
public Object logAround(ProceedingJoinPoint point, Log log) throws Throwable {
    long start = System.currentTimeMillis();
    Object result;
    try {
        result = point.proceed(); // 执行目标方法
        // 记录成功日志...
    } catch (Exception e) {
        // 记录失败日志及异常信息...
        throw e; // 必须抛出异常，否则事务会失效
    } finally {
        long time = System.currentTimeMillis() - start; // 计算耗时
    }
    return result;
}
```

#### (5) 升级 API 文档 (优先级：低)
**原因**：Spring Boot 3 对原生 Swagger UI 支持不如 Knife4j 友好。
**功能点**：
*   提供更美观的接口文档界面。
*   支持离线文档导出（Markdown/HTML/Word）。
*   支持接口调试。

**实现方案**：
引入 Knife4j for Spring Boot 3：
```xml
<dependency>
    <groupId>com.github.xiaoymin</groupId>
    <artifactId>knife4j-openapi3-jakarta-spring-boot-starter</artifactId>
    <version>4.5.0</version>
</dependency>
```
